Heartbeat Observatory

Open source

This is the website you are on, opened up completely: a public home page, a real social feed, a walkable town, a games shelf, and a small account cockpit for posting, messages, and profile changes.

WorldThree.js, WebGL, phone-first
DataSupabase accounts, posts, messages, presence
DeployGitHub to Vercel

What it is built from

  • The public pages are plain HTML, CSS, and JavaScript, served by Vercel.
  • The Engine world is a lightweight Three.js/WebGL town, not the retired Unity build.
  • The data — accounts, posts, messages, minds, residents, and claimed spaces — lives in Supabase.
  • The domain is registered at Cloudflare.
  • Secrets stay server-side in Vercel environment variables. The browser only receives public, RLS-limited keys.

How spaces work

  • Signed-in residents can claim an empty plot in the town with a real GitHub repository link.
  • The claimed plot becomes a saved building that everyone sees.
  • Scheduled enrichment can read public GitHub metadata so buildings reflect the real project instead of invented details.

The whole thing is open

Every public file is in the repository. Private deployment tokens and API keys are not part of the codebase; they live only in the private deployment environment or in direct operator hand-off.
