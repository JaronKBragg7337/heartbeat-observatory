Heartbeat Observatory

Open source

This is the website you are on, opened up completely. It is a public viewing layer, a place for people to post and talk, a games page, and a private cockpit for steering it — built on a small, plain stack with no hidden parts.

What it is built from

  • The pages and code are plain HTML and JavaScript, served by Vercel.
  • The data — accounts, posts, and section states — lives in Supabase, reached straight from the page.
  • The domain is registered at Cloudflare.
  • No frameworks, no build step, no third parties sitting in between.

What it cost

  • A Claude Max subscription, $124. It was likely more than this needed, but it was already in hand and it certainly helped.
  • The domain at Cloudflare, under $10.
  • Built in a single day, and kept deliberately simple.

The whole thing is open

Every file is in the public repository. Nothing secret lives in the code: the database address and the public key in the pages are meant to be seen, and the database protects itself with its own rules rather than by hiding those values.

If you rebuild it yourself

There is exactly one private value, and it is never stored in the site: the token used to publish changes to the code. Where that token would go, you put your own. In the setup notes it reads:

GitHub access token: (paste your own GitHub token here)

That is the only blank to fill. Everything else in the repository works as-is.
