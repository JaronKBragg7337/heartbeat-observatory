# World 2 assets
- `canopy_leaf.webp` - copied from World 1's kit (`/engine/hub/assets/textures/`, authored for the town; see its README).
- `ground_detail.webp`, `ground_normal.webp` - from ambientCG **Grass005** (CC0 1.0, https://ambientcg.com), 512 px; the colour
  map was turned grey and brightened (mean ~244) so the terrain's painted zones keep their own colour. Tiled every ~3 m.
- The needle-branch card for the pines is painted at runtime (`w2NeedleTexture()` in main.js); no file.
