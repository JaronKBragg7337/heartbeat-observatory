Lit window = 1, dark window = 0. Read each column of windows top to bottom: 7 windows make 7 bits, and 7 bits is one letter in plain computer text (ASCII). 1110100 is t, 1101000 is h, 1100101 is e. 38 columns across 8 buildings, 38 characters, spaces included.
