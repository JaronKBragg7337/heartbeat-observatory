# Heartbeat town art kit

`heartbeat-town-realism-v1.glb` is the adult, grounded visual shell for the live town.
It was authored procedurally in Blender so its scale, palette, provenance, and regeneration
path stay under repository control.

## Contents

- Nine differentiated civic/residential facades with modeled trim and window depth.
- Paved square, roads, planting beds, mature trees, lamps, benches, bins, cafe furniture,
  fountain, and bandstand.
- A reusable named avatar template with separate skin/clothing/hair materials and gait
  pivots. Runtime appearance colors and names still come from the live application.
- `source/heartbeat-town-realism-v1.blend` is the editable source.

The runtime retains the existing invisible building colliders, doors, plots, note bars,
Supabase presence, and world data. The GLB is visual presentation, never interaction truth.

## Build

From the repository root with Blender available on `PATH`:

```powershell
blender --background --python tools/blender/generate_heartbeat_town_realism.py
```

The script saves the `.blend`, exports a Draco-compressed GLB, and renders the review image
at `docs/art/heartbeat-town-realism-v1.png`. Keep the shipping GLB near or below 1.5 MB and
inspect the browser result on both desktop and a phone-sized viewport after every change.

## Provenance and licensing

All geometry in the kit is generated by this repository's Blender script. Poly Haven's CC0
library was reviewed as a future source for selective hero materials. It was not mixed into
v1 because the candidate photogrammetry assets were heavier and visually inconsistent with
the town's coherent authored scale. Record any future imported asset, source URL, license,
and local modification in this file before it ships.

### Imported surface textures (added 2026-08-03)

`assets/textures/*.webp` — **source: [ambientCG](https://ambientcg.com), licence: CC0 1.0
(public domain, no attribution required).** Downloaded as 1K PNG/JPG map sets and converted
locally to WebP by `hb-harness/convert-tex.js`: colour 1024 px @ q0.82, normal 512 px @
q0.85, roughness and ambient occlusion 512 px @ q0.78. Total shipped payload 2.17 MB.

Normals are held at 512 deliberately — WebP encodes high-frequency normal noise poorly
(a 1024 asphalt normal alone cost 486 KB, a fifth of the whole budget) and the extra
resolution is not resolvable on a phone at 1–4 m tiling.

| Asset | Used as | Tile size (m) | How that size was determined |
|---|---|---|---|
| Bricks097 | red brick facades | 2.400 × 1.200 | **measured**: 32 px course pitch, 16.00 courses/tile @ 75 mm (autocorrelation r=1.0) |
| Bricks075A | buff / rough stone | 2.00 × 1.00 | published: ambientCG 200 × 100 cm |
| Travertine009 | limestone trim, plinth, cornice | 1.20 × 1.20 | published |
| Concrete034 | paths, kerbs | 1.10 × 0.55 | published |
| PavingStones138 | plaza setts | 1.25 × 2.50 | published (pixel aspect 1:2 agrees) |
| RoofingTiles013A | slate roofs | 2.90 × 2.90 | published |
| Bark014 | tree trunks | 1.20 × 1.20 | published |
| Asphalt033 | roads | 4.00 × 4.00 | **estimate** — asphalt has no periodic cue to measure |
| Grass005 | lawns | 2.00 × 2.00 | **estimate** — blade length implies ~2 m |
| Planks037A | doors | 2.00 × 2.00 | **estimate** — plank width implies ~2 m |

Estimates are labelled as such in `engine/hub/surface.js` (`sizeSource` on each card) and
are the ones to re-measure first if a surface reads at the wrong scale.

Re-download and re-convert:

```powershell
node "hb-harness/convert-tex.js" "<repo>/engine/hub/assets/textures"
```
