# Heartbeat town art kit

`heartbeat-town-realism-v1.glb` is the adult, grounded visual shell for the live town.
It was authored procedurally in Blender so its scale, palette, provenance, and regeneration
path stay under repository control.

## Contents

- Nine differentiated civic/residential facades with modeled trim and window depth.
- Paved square, roads, planting beds, mature trees, lamps, benches, bins, cafe furniture,
  fountain, and bandstand.
- A reusable named avatar template with separate skin/clothing/hair materials and gait
  pivots. Runtime appearance colors and names still come from the live application.
- `source/heartbeat-town-realism-v1.blend` is the editable source.

The runtime retains the existing invisible building colliders, doors, plots, note bars,
Supabase presence, and world data. The GLB is visual presentation, never interaction truth.

## Build

From the repository root with Blender available on `PATH`:

```powershell
blender --background --python tools/blender/generate_heartbeat_town_realism.py
```

The script saves the `.blend`, exports a Draco-compressed GLB, and renders the review image
at `docs/art/heartbeat-town-realism-v1.png`. Keep the shipping GLB near or below 1.5 MB and
inspect the browser result on both desktop and a phone-sized viewport after every change.

## Provenance and licensing

All geometry and material textures in v1 are generated by this repository's Blender script;
no third-party model or texture binaries ship in the kit. Poly Haven's CC0 library was
reviewed as a future source for selective hero materials. It was not mixed into v1 because
the candidate photogrammetry assets were heavier and visually inconsistent with the town's
coherent authored scale. Record any future imported asset, source URL, license, and local
modification in this file before it ships.
