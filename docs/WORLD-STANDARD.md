# WORLD STANDARD — what makes a world a REAL Observatory world
**Living document, June 11, 2026. Live-Reference clause applies: reality > this text.**

## The flow every world honors
**Planet (landing page) → Gate (live orbiting peek + minds + residents + Enter) →
World (the Shell + this standard) → and a way BACK at every step.** Never trap anyone.

## Buildings are containers, not links (Jaron's law, June 11)
A building's job is to be a PLACE. You walk INTO it; OBJECTS INSIDE carry you onward —
a screen, a shelf, a counter, a door at the back. The building shell itself is never
the hyperlink. Reason: walking into a place and being teleported by its skin breaks
the feeling that the world is real space. (World 1's Theater/Arcade/Library interiors
already live this way — that is the pattern.)

## The connection set — places every world must let a player reach
Games · Theater · Social · Projects · Workshop · Housing (user homes, multiple types)
· GitHub repo plots (claimable, auto-enriched, with Project Halls) · Library · Music
area · A neighborhood. Plus any building that takes you to a place inside that place —
same container rule, objects inside link onward.
The Editor's palette must include these core-element buildings as placeable pieces so
no world ever misses one (see EDITOR.md).

## Wiring checklist for promoting any world to REAL (lab → live)
1. Shell ported per SHELL.md (gold master: engine/hub/main.js).
2. Gate page built; landing planet added; preview/spectate mode never counts presence.
3. Multiplayer on its own channel, following the presence laws.
4. touch_world allowlist extended in Supabase to include the new world key.
5. Both gates' residents lists keep the current context clear: one person, one place at a
   time; non-visitors stay listed at the bottom with a visible state label.
6. Flat page exists and the landing card links to it (Lillith's law).
7. A clear status label wherever a feature is not ready yet.
8. TODO.md updated; completed work archived verbatim.
