Key Drop

Paste a new API key from anywhere. It gets locked on your phone before it's sent, and only the MSI can unlock it. The MSI puts it where the tools read it, tests it, and buzzes your phone. Nobody, including this page, can read it back.

Polymarket US

  1. polymarket.us, then API keys, then create a new key (withdrawals on).
  2. Paste the Key ID and the Secret below.

The MSI restarts the trading service with it and checks the balance. If that fails it goes back to the old key on its own.

Kraken

  1. First save where withdrawals should go: Funding, then Withdraw, add the destination (Kraken only sends to saved ones).
  2. Settings, then API, then create a key with every permission you want, including Withdraw Funds.
  3. Paste both values below.

The MSI tests it with a balance check before it replaces the old key.

Any other key

Saved into the MSI's main key file under the name you give it (capital letters, numbers and _ only, like XAI_API_KEY). Tell Claude the name afterwards so the right tool uses it.
