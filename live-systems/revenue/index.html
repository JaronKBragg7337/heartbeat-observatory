    Why most of it is thrown away

    The screening

    Measured on 2026-09-08 rather than assumed: GitHub carried 558 open issues labelled 💎 Bounty and 4,280 labelled bounty, which looks like a rich market. But all 25 of the freshest were agent-practice repos or bounty mills, with identical titles copy-pasted across unrelated repositories, each drawing 17–46 comments within a day — other agents racing. One repository advertised $8k, $7k, $5k and $4k at the same time, every one unclaimed for 115 days.

    Four signals screen those out: repository naming, comment pile-on rate, implausible pay-for-effort, and a repository-level check for boards that advertise large sums they never settle. Game jams are listed with their prize unknown rather than guessed, because itch.io renders jam pages in the browser and a fetch returns a shell with no prize text in it.
